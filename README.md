# Naimas Perfume

A modern and elegant perfume e-commerce frontend built with React, TypeScript, Vite, and Tailwind CSS.

## Tech Stack

* React 19
* TypeScript
* Vite
* Tailwind CSS
* Motion
* Lucide React
* Google GenAI
* Express.js

## Features

* Modern premium UI/UX
* Responsive design
* Product showcase
* Smooth animations
* Interactive components
* Mobile-friendly experience
